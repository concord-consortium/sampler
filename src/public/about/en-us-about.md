## Building Sampler Models
Use the Sampler to build a model that randomly samples "items" from one of three different devices:
1. A **Mixer** representing items as placed in a container.
2. A **Spinner** that chooses items from sectors of a circle.
3. A **Collector** that chooses cases (rows) from a dataset.

Use the +, –, and … buttons to change the items contained in a **Mixer** or **Spinner**. Click on item labels to edit. 
In the spinner, click on a sector to edit the label or percentage for the sector. You can also change the percentage by 
dragging the edges of sectors in the Spinner.

Change the number of items to **Select** in each sample by editing the number of items. You can also change the number
of **Samples** to collect in each experiment.
Sampling is done **with replacement** by default but can be changed **without replacement**.

You can change **Select** to **Repeat** and use the **Until** box to define a condition for when to stop sampling.

The default attribute name of a device is **output**, but you can edit this to be an attribute name appropriate to
your model.

Press **START** to select items for each sample. Control the **Speed** of sampling using the slider next to
the **STOP** button.
