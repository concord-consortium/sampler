## Création de Modèles d'Échantillonnage

Utilisez l'Échantillonneur pour créer un modèle qui sélectionne aléatoirement des "éléments" à partir de l'un des trois dispositifs différents :

1. Un **Mélangeur** représentant des éléments placés dans un conteneur.
2. Une **Roue** qui choisit des éléments parmi les secteurs d'un cercle.
3. Un **Collecteur** qui sélectionne des cas (lignes) à partir d'un ensemble de données.

Utilisez les boutons +, –, et … pour modifier les éléments contenus dans un **Mélangeur** ou une **Roue**. Cliquez sur les étiquettes des éléments pour les éditer.  
Dans la roue, cliquez sur un secteur pour modifier l’étiquette ou le pourcentage du secteur. Vous pouvez également changer le pourcentage en faisant glisser les bords des secteurs dans la Roue.

Changez le nombre d’éléments à **Sélectionner** dans chaque échantillon en modifiant le nombre. Vous pouvez aussi changer le nombre d’**Échantillons** à collecter dans chaque expérience.  
Par défaut, l’échantillonnage se fait **avec remise**, mais peut être changé **sans remise**.

Vous pouvez changer **Sélectionner** par **Répéter** et utiliser la case **Jusqu’à** pour définir une condition indiquant quand arrêter l’échantillonnage.

Le nom d’attribut par défaut d’un dispositif est **output**, mais vous pouvez le modifier par un nom d’attribut approprié à votre modèle.

Appuyez sur **DÉMARRER** pour sélectionner des éléments pour chaque échantillon. Contrôlez la **Vitesse** de l’échantillonnage à l’aide du curseur situé à côté du bouton **ARRÊTER**.
