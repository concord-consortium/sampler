## Construcción de Modelos de Muestreo

Utilice el Muestreador para construir un modelo que seleccione aleatoriamente "elementos" de uno de tres dispositivos diferentes:

1. Un **Mezclador** que representa elementos colocados en un contenedor.
2. Una **Ruleta** que elige elementos de los sectores de un círculo.
3. Un **Recolector** que selecciona casos (filas) de un conjunto de datos.

Use los botones +, –, y … para cambiar los elementos contenidos en un **Mezclador** o una **Ruleta**. Haga clic en las etiquetas de los elementos para editarlas.  
En la ruleta, haga clic en un sector para editar la etiqueta o el porcentaje del sector. También puede cambiar el porcentaje arrastrando los bordes de los sectores en la Ruleta.

Cambie el número de elementos a **Seleccionar** en cada muestra editando el número de elementos. También puede cambiar el número de **Muestras** que desea recopilar en cada experimento.  
Por defecto, el muestreo se realiza **con reemplazo**, pero puede cambiarse **sin reemplazo**.

Puede cambiar **Seleccionar** por **Repetir** y usar la casilla **Hasta** para definir una condición que indique cuándo detener el muestreo.

El nombre de atributo predeterminado de un dispositivo es **salida**, pero puede editarlo por un nombre de atributo apropiado para su modelo.

Presione **INICIAR** para seleccionar elementos en cada muestra. Controle la **Velocidad** del muestreo utilizando el control deslizante junto al botón **DETENER**.
